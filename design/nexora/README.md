# Pachet de export Nexora

## Conținut

- `png/desktop/` — toate ecranele la 1440 × 1200px
- `png/mobile/` — toate ecranele la 390 × 844px
- `DESIGN-SYSTEM.md` — culori hex, fonturi, raze și spațieri
- `TEXTE-UI-RO.md` — inventarul textelor UI în limba română
